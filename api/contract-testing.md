# Contract Testing

Contract testing verifies that a provider and its consumers agree on the shape and meaning of an API interaction.

## Practices

Define required fields, types, status codes, headers, error formats, and compatibility rules as executable contracts. Validate consumer expectations against provider changes before deployment. Version breaking changes deliberately and keep contract failures actionable with the owning service and interaction context.

Contracts complement, rather than replace, integration and end-to-end coverage.

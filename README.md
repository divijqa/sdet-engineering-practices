# SDET Engineering Practices

A technical repository documenting engineering-driven practices performed by SDETs across UI and API layers.  
This includes framework architecture, automation design patterns, reusable libraries, CI/CD integration, quality gates, and tooling required to enable scalable and maintainable test automation.

This repo complements the QA Ops repository by focusing on the engineering side of quality.

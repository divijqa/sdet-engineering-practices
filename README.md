# SDET Engineering Practices

Engineering-driven practices for building scalable, maintainable, and reliable test automation.

This repository documents practical SDET engineering patterns across UI automation, API automation, framework architecture, CI/CD, and quality engineering.

## Engineering Focus

### UI Engineering

Modern UI automation engineering practices covering:

- Playwright
- Selenium
- Framework architecture
- Locator strategy
- Page Object Model
- CI/CD integration

### API Engineering

API automation and service-level validation covering:

- API test architecture
- REST API automation
- Contract testing
- Schema validation
- Authentication
- CI/CD integration

### Engineering Foundations

Core engineering practices covering:

- Framework architecture
- Reusable libraries
- Test data engineering
- Quality gates
- Pipeline orchestration
